## Caveats

- **ENUM_CAPITALIZATION_NOT_GUARANTEED**: local stage 5 compares enum members exactly, so a case variant is refused.
- **REFUSAL_OR_MAX_TOKENS_MAY_NOT_MATCH**: the completion is read from stop_reason before any parse, unchanged.
- **INTERNAL_COMPLEXITY_LIMITS_NOT_VERIFIABLE_WITHOUT_A_PROVIDER_REQUEST**: the explicit limits hold (1 strict tool, 0 optional parameters, 0 union types); the internal grammar-size limits are undocumented, and a schema too complex to compile is a 400 error the one approved request would spend.
- **FIRST_REQUEST_COMPILATION_LATENCY_NOT_ESTABLISHED**: the first request with a schema waits while its grammar compiles, for an undocumented time up to a 180-second compilation timeout; the 60-second request timeout is kept as frozen, so a long compilation would end the one call.
- **INJECTED_FORMAT_PROMPT_TOKENS_NOT_ESTABLISHED**: the documentation says structured outputs add a system prompt explaining the format; its size is not documented and it is not in the request body the estimate measures.
- **TOOL_SCHEMA_CACHED_24_HOURS**: the projected schema is cached by the provider for up to 24 hours; it carries no TED value, no identifier and no subject, which this gate checks.
