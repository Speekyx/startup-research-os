## New requirements for the registry

### `THE_RETRIEVABLE_FRAME_IS_NOT_THE_MEASURED_FRAME`

*From Mission 1.62.* An apparatus can measure the whole internet and expose to any given requester only a slice of it. What bounds a Claim is the frame the acquisition surface EXPOSES, never the frame the apparatus MEASURES. Where the exposed slice is defined by who is asking, two requesters retrieve two different populations and no single proposition about the whole can be witnessed through it.

*Demonstrated by:* A partner candidate that performs daily internet-wide scanning and whose reporting API states that a requester only gets data on the networks they are responsible for. It scans everything and can show us only ours.

*Distinct from:* FRAME_INSIDE_THE_DEFINITION concerns an apparatus measuring share within its own reach. LINEAGE_EXHAUSTIVENESS_IS_NOT_FRAME_EXHAUSTIVENESS separates who produced an observation from which addresses were reached. Neither covers a global measured frame with a per-requester retrievable one.

### `DEFAULT_DATA_SURFACE_MUST_NOT_OVERRIDE_QUALIFIED_EXPOSURE_PATH`

*From Mission 1.62.* Where an apparatus qualifies only through a non-default observation-addressable surface, a collector must bind explicitly to that surface. A default surface that silently returns the latest state is the rejected temporal object, and a collector omitting the selector reads it while a record elsewhere says the gate passed.

*Demonstrated by:* The anchor's API reference stating that if the index parameter is not supplied, the search is conducted using the latest publicly available internet scan data. The qualifying path requires an argument that is easy to omit, and omitting it is silent.

*Distinct from:* OBSERVATION_ADDRESSABLE_EXPOSURE governs whether a qualifying mechanism EXISTS. This governs whether an implementation USES it, which no existing rule reaches. It is a constraint on collector construction rather than on apparatus selection.
