# CLAUDE.md — pointer

**This file carries no rules of its own and is not authoritative.** It exists
only because agent tooling loads a `CLAUDE.md` from the repository root, and the
operating contract lives one directory down, where it would otherwise not be
read.

The operating contract for this repository is **`docs/CLAUDE.md`**.

## Before performing any task

1. Read `PROJECT_MANIFEST.md`.
2. Read `docs/CLAUDE.md`, and execute the reading order in its §Boot Sequence.

The boot sequence is deliberately **not** restated here. A second copy would
drift from the first, and a drifted copy of an operating contract is worse than
no copy: it is a rule that looks authoritative and is wrong. `docs/CLAUDE.md`
§Change control governs how that contract changes; this file is not a place to
change it.

`PROJECT_MANIFEST.md` §Authoritative Documents lists every document that does
define the project. This one is not among them, by design.
